# New Narrative — главная страница

Next.js 15 (App Router) · TypeScript · Tailwind CSS · дизайн-система Glow · деплой на Vercel.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполните переменные
npm run dev                  # http://localhost:3000
```

`npm run build` — сборка. Перед ней запускается `check-placeholders`.

## Как править тексты

Все тексты лежат в **`content/ru.json`**, разбиты по блокам. Компоненты трогать не нужно.

- Значение `null` скрывает элемент (например `contact.text`, подпись под заголовком формы).
- Три скрина на первом экране: `hero.screens` (файлы в `public/images/cases/`, при замене сохраняйте пропорции ≈ 16:10 и 4:3).
- Английская версия: положите рядом `content/en.json` той же структуры.

## Заглушки и защита от публикации

Текст в квадратных скобках, например `[X ₽]` или `[2–3]`, — это заглушка.
`scripts/check-placeholders.mjs` ищет их во всех `content/*.json`:

- **production на Vercel** (`VERCEL_ENV=production`): сборка падает со списком мест;
- **preview и локально**: только предупреждение;
- принудительно строго: `CHECK_PLACEHOLDERS=strict npm run check-placeholders`.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | адрес сайта для canonical, sitemap, Open Graph |
| `NEXT_PUBLIC_YM_ID` | ID счётчика Яндекс Метрики |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | бот и чат для заявок |
| `LEAD_EMAIL_TO` | куда слать заявки (по умолчанию main@newnarrative.ru) |
| `LEAD_EMAIL_FROM`, `RESEND_API_KEY` | отправка почты через Resend |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | необязательно: общий лимит заявок; без них лимит в памяти |

Секреты не коммитятся: `.env*` в `.gitignore`.

## Форма заявки

`POST /api/lead`: проверка полей на сервере (zod, общие правила с клиентом), тело до 10 КБ, ловушка `website`,
не больше 5 заявок за 10 минут с IP. Заявка уходит в Telegram и на почту; принята, если сработал хотя бы один канал,
иначе ответ 502. Заявки не хранятся, в логах нет персональных данных.

## Аналитика

Цели Метрики: `cta_click` (параметр `place`), `form_start`, `form_submit`, `case_click` (параметр `case`),
`scroll_50`, `scroll_90`. Скрипт грузится отложенно (`lazyOnload`).

## Деплой

1. Vercel → **Add New → Project → Import** этого репозитория. Framework определится сам (Next.js).
2. Settings → Environment Variables: переменные из таблицы.
3. Каждый push в ветку = preview-деплой; merge в `main` = production.

## Допущения (вопросы к заказчику)

- Структура и тексты страницы взяты с https://newnarrative.vercel.app: первый экран, «Игры, которые сработали», «Нам доверяют»,
  «Создаем форматы…», «От одной кампании…», «Готовы обсудить вашу игру?». Добавлен только блок «Ваша аудитория уже играет».
  Таблица «Где игра превращается в деньги» и FAQ из ТЗ убраны. Поля формы «Бюджет» и «Средний чек или маржа» остались от ТЗ.
- Логотипы клиентов набраны текстом: нужны файлы и разрешение на публикацию.
- Ссылки на Политику конфиденциальности, Оферту и «Еще больше кейсов» пока ведут на `#` (`footer.legal[].href`, `cases.more.href`
  в `content/ru.json`): замените на реальные адреса до запуска. Защита от заглушек их больше не ловит, поэтому не забудьте.
- Подстраницы `/events`, `/digital`, `/futbolario`, `/match3-game`, `/car-simulator` в этот репозиторий не входят:
  если они живут в другом проекте, настройте rewrites/редиректы или перенесите их.
- Шрифты подключены локально (Fontsource): Unbounded, Onest, IBM Plex Mono, `font-display: swap`.
- Блог и Гайды скрыты, пока таких страниц нет.
- Блок «Ваша аудитория уже играет» (`audience` в `content/ru.json`): цифры из исследования НАФИ «Гейминг в России — 2026»
  (октябрь 2025). Два числа лежат в `audience.stats` (всего играют, играют каждый день); они считаются от разных групп
  (россияне 14+ и взрослые), это сказано в `audience.source.baseNote`. При обновлении цифр поправьте и сноску.
